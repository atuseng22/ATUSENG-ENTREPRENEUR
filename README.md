# ATUSENG ENTREPRENEUR

Website layanan digital UMKM milik Fariz (Atuseng), Yogyakarta.

## Isi proyek

Website statis HTML, CSS, dan JavaScript tanpa proses build atau database. Halaman berisi Home, Services, Packages, About, dan Contact. Pemesanan membuka draf WhatsApp; website tidak menerima pembayaran atau menyimpan pesanan sendiri.

- `index.html`: halaman utama.
- Berkas CSS: tampilan dan penyesuaian ukuran layar.
- Berkas JavaScript: intro, suara opsional, animasi, navigasi, dan formulir paket.
- Berkas PNG: logo, potret yang telah diedit, dan aset yang dirujuk stylesheet.

Font dimuat melalui Google Fonts. Suara intro hanya aktif setelah tindakan pengunjung.

## Menjalankan

Buka `index.html` di browser untuk pratinjau lokal. Tidak perlu memasang paket. Untuk publikasi di masa depan, direktori ini dapat menjadi direktori keluaran hosting statis.

## Status

Disiapkan untuk penyimpanan GitHub, belum dipublikasikan melalui hosting dan belum disambungkan ke domain. Tidak ada GitHub Actions atau konfigurasi GitHub Pages yang mengaktifkan publikasi otomatis.

Delapan kelompok pemeriksaan otomatis pada versi sumber telah lolos: formulir/tautan, galaksi, intro, suara, service, delapan adegan, meteor potret, dan logika responsif. Pemeriksaan tersebut menggunakan simulasi, bukan pengganti pengujian visual pada browser/perangkat asli.

Sebelum peluncuran, uji laptop dan HP asli, formulir paket, tautan WhatsApp/Instagram, keterbacaan, serta kelancaran animasi. Tetapkan domain sebelum menambahkan canonical URL dan alamat gambar pratinjau sosial absolut.

## Pembaruan

Simpan perubahan sebagai commit kecil dan pertahankan versi sebelumnya agar dapat dipulihkan. Jangan mengunggah password, token, foto mentah, screenshot pribadi, atau data pelanggan. Akun dan domain tetap dikelola oleh pemilik.

Kode dan aset tidak diberi lisensi penggunaan ulang publik.
